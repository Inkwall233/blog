# 关于本站

你好，我是 **inkwall** 👋

这里是我的个人博客，记录学习路上的点滴思考与技术沉淀。

## 为什么要写博客

> 不积跬步，无以至千里；不积小流，无以成江海。

写博客的初衷很简单——**倒逼自己输出**。

看过的文章、读过的源码、踩过的坑，如果不整理成文字，过不了多久就会忘掉。所以这个仓库既是我的学习笔记，也是我的知识后花园。

## 博客内容

目前主要关注以下方向：

- 🟦 **TypeScript** — 类型体操、类型系统与工程实践
- ⚛️ **React** — Hooks 原理、状态管理、性能优化
- 🤖 **AI 与 MCP** — 大模型应用、工具协议、智能体开发
- 📦 **工程化** — Monorepo、构建工具、前端基础设施
- ✍️ **随笔** — 偶尔的读书/生活感悟
